# 🌱 Crescer Juntos - Frontend

Aplicação frontend do projeto **Crescer Juntos**, desenvolvida em **React Native**, como Trabalho de Conclusão de Curso (TCC) do curso de Tecnologia em Sistemas para Internet do Instituto Federal Catarinense (IFC) - Campus Camboriú.

---

## 📖 Sobre o Projeto

O **Crescer Juntos** é uma plataforma colaborativa voltada à troca, doação e compartilhamento de plantas ornamentais, hortaliças e medicinais entre usuários interessados em jardinagem, cultivo doméstico e sustentabilidade.

Este repositório contém o desenvolvimento completo do **frontend da aplicação mobile**, responsável pela interface e interação dos usuários com a plataforma.

---

## 🚀 Funcionalidades

- ✅ Cadastro de usuários
- ✅ Autenticação de usuários
- ✅ Gerenciamento de perfil
- ✅ Cadastro de plantas
- ✅ Gerenciamento de plantas
- ✅ Envio e recebimento de mensagens
- ✅ Solicitação de trocas
- ✅ Gerenciamento de trocas
- ✅ Encerramento de sessão

---

## 🛠️ Tecnologias Utilizadas

- React Native
- Expo
- TypeScript
- Expo Router
- Context API
- JavaScript
